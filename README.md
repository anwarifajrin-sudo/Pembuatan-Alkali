# DompetKu Pro - Aplikasi Manajemen Keuangan Pribadi (PWA)

Aplikasi manajemen keuangan pribadi berbasis web (Progressive Web App) yang berjalan 100% offline di HP Android (Redmi/HyperOS) dan iOS.

## Cara Instal di HP
1. Buka `index.html` atau `dompetku.html` di Google Chrome HP.
2. Ketuk menu titik tiga di kanan atas Chrome, lalu pilih **Tambahkan ke layar utama (Add to Home Screen)**.
